Why sponsor this

We hoped banks would back it. They back incumbents. So it's being built independently — and the honest way to keep it open and moving is for the community and the ecosystem to sponsor the work directly. Your sponsorship funds full-time development and an independent security audit, so this can be trusted with real value while staying MIT and self-hostable.

What's already built

Multi-chain

Base, Optimism, Arbitrum, Polygon — built on Circle-native USDC.

CCTP V2 cross-chain

Native USDC transport between chains (burn → attest → mint).

Gasless & non-custodial

EIP-3009 signed authorizations. The SDK never holds your funds.

Self-hostable

Run your own facilitator. No portal lock-in, no middleman.

Tested

404 unit tests across the SDK. Open code you can read and audit.

Standards-based

Built on the x402 protocol (now under the Linux Foundation).

honest status Built and unit-tested. The next milestone is a live testnet run with public transaction hashes and a security audit — which is what your sponsorship pays for.
